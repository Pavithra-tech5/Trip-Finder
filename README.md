# Trip Finder – Travel Website

A responsive travel website inspired by modern travel platforms, built using **HTML5 and CSS3**.

## Features

* Responsive navigation bar
* Travel hero section with search area
* Popular destinations
* Things to do section
* Popular hotels section
* Restaurant cards
* Travel inspiration section
* Responsive design for desktop, tablet, and mobile
* CSS hover effects and card layouts

## Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
* Media Queries

## Project Structure

```text
trip-finder-website/
│
├── index.html
├── style.css
└── images/
```

## Purpose

This project was created to practice building a responsive and professional travel website using only HTML and CSS.
